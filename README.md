# Student Grade Calculator

## Description

A beginner-friendly Python project that calculates a student's total marks, percentage, and grade.

## Features

- Takes student name as input
- Takes marks for five subjects
- Calculates total marks
- Calculates percentage
- Displays the student's grade

## Technologies Used

- Python

## How to Run

1. Install Python.
2. Open the project in VS Code.
3. Run `student_grade_calculator.py`.
4. Enter the student details and marks.
5. View the result.
